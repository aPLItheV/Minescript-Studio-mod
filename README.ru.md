# Minescript Studio
Клиентский мод Fabric для Minecraft 26.3: редактор и настройки для Minescript прямо в игре.
Один и тот же jar работает на Windows, Linux и macOS.

## Сборка

Нужен JDK 25 и интернет.

Windows: `gradlew.bat build`.
Linux/macOS: `./gradlew build`.

Готовый мод: `build/libs/minescript-studio-0.4.0.jar` (без `-sources` в имени).

## Использование

- `/mse` открыть редактор (откроется последний файл), `/mse имя` открыть или создать файл
- клавиша «Открыть редактор» (по умолчанию - K) и «Запустить последний скрипт» (по умолчанию не назначена):
- настройки: кнопка «Настройки» в редакторе
