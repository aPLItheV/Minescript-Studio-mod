# Minescript Studio
Клиентский мод Fabric для Minecraft 26.3: редактор и настройки для Minescript прямо в игре. Редактируйте, сохраняйте и запускайте скрипты Minescript, не выходя из Minecraft. Подсветка синтаксиса, предложения для API Minescript, поиск в файле, проверка синтаксиса, сворачиваемая консоль, действия с файлом при щелчке правой кнопкой мыши, настраиваемые горячие клавиши и настройки для папки скриптов и пути Python

## Сборка

Нужен JDK 25 и интернет.

Windows: `gradlew.bat build`.
Linux/macOS: `./gradlew build`.

Готовый мод: `build/libs/minescript-studio-0.4.0.jar` (без `-sources` в имени).

## Использование

- `/mse` открыть редактор (откроется последний файл), `/mse имя` открыть или создать файл
- клавиша «Открыть редактор» (по умолчанию - K) и «Запустить последний скрипт» (по умолчанию не назначена):
- настройки: кнопка «Настройки» в редакторе
